# Calculadora JS

Uma calculadora feita com HTML, CSS e JavaScript para praticar um pouco de desenvolvimento web.

## Funcionalidades

- Adição, subtração, multiplicação e divisão
- Operações com números decimais
- Botão para limpar o visor
- Botão para apagar o último caractere
- Exibição dos resultados com até 5 casas decimais
- Tratamento de erros em operações inválidas

## Tecnologias

- HTML
- CSS
- JavaScript

## Como executar

1. Clone o repositório:

   `git clone URL_DO_REPOSITORIO`


2. Abra a pasta do projeto.
3. Execute o arquivo `index.html` no navegador.

## Objetivo

Fiz esse projeto para praticar JavaScript, principalmente funções, eventos, manipulação do DOM e lógica de programação.
