# Lista de Tarefas

Um projeto simples de lista de tarefas feito com HTML, CSS e JavaScript para praticar manipulação do DOM e eventos.

## Funcionalidades

- Adicionar tarefas à lista
- Editar tarefas existentes
- Remover tarefas individualmente
- Limpar todas as tarefas de uma vez
- Impedir o cadastro de tarefas vazias
- Exibir mensagens de confirmação e erro

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone este repositório:
   ```bash
   git clone https://github.com/TaroNukem/Projetos-JavaScript
   ```
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` no navegador.

## O que pratiquei

- Seleção de elementos com `getElementById()`
- Eventos com `addEventListener()`
- Manipulação do DOM
- Arrays e métodos como `push()` e `splice()`
- Criação de elementos com `createElement()`
- Validação de campos com `trim()`
